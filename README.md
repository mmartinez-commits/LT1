# The circular garden

This is a program that runs the formulas by asking the radius of the garden
## Problem Identification:
I showed problem identification by asking myself 

- "What is the problem?"

The problem here simplified is trying to create a calculator for a circle with one input being the radius

## Problem Decomposition:
I showed Problem Decomposition by asking myself 

- "What parts can be broken down to simplify?"

I showed it as I decomposed the problem into formulas for Area, Circumference, and the neccessary math libraries.

which I used multiple times
## Data Representation:

`float(input("What is the radius of the garden?: "))`

## Algorithm Development:

I input the area then the formulas will process it then display it all

# How to use it?

## Input the Radius
When the radius is asked, do not include other characters that is NOT digits or it will break

## Read it
Read it the answers. Example: 

- Area of the garden is 78.54
- Circumference of the garden is 31.42
- Square root of the area is 8.86
- Rounded down area is 78
- Rounded up area is 79

The input for this example is 5
